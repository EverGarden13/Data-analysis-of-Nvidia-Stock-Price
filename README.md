# NVIDIA Stock Price Analysis

This project performs comprehensive analysis of NVIDIA Corporation's (NVDA) stock price data using various data science and machine learning techniques.

## Project Overview

The project includes several components:

- **Exploratory Data Analysis (EDA)**: Initial analysis of the stock price data
- **Time Series Analysis**: Statistical analysis of stock price patterns
- **Machine Learning Models**: Various ML approaches for price prediction
- **LSTM Model**: Deep learning approach for time series forecasting

## Dataset

The dataset used in this project is sourced from Kaggle:
https://www.kaggle.com/datasets/flynn28/nvidia-stock-price-data

## Project Structure

- `EDA.ipynb`: Exploratory data analysis notebook
- `TS.ipynb`: Time series analysis notebook
- `ML.ipynb`: Machine learning models notebook
- `LSTM.ipynb`: LSTM model implementation
- `test.py`: Testing script
- `parameters.md`: Model parameters documentation
- `plots/`: Directory containing generated visualizations
- `best_model.pth`: Saved best performing model

## Requirements

The project requires Python and several data science libraries. Install the requirements using:

```bash
pip install -r requirements.txt
```

## Usage

1. Clone the repository
2. Install the requirements
3. Run the notebooks in the following order:
   - EDA.ipynb
   - TS.ipynb
   - ML.ipynb
   - LSTM.ipynb

## Results

The analysis includes:
- Historical price trends
- Statistical analysis
- Machine learning predictions
- LSTM-based forecasting
